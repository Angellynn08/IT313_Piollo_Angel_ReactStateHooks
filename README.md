
# IT313 Lab Activity 5
## React State & Hooks in Action

### Project Title
Lab Timer & Practice Tracker

### Description
This is a simple React Native application built using Expo.
It helps students track their solved practice problems and
monitor their practice time using a stopwatch.

### Features
- Track the number of solved problems
- Increase the counter using the Solve +1 button
- Reset the solved counter
- Display "Great job!" after solving five problems
- Start and pause the stopwatch
- Display elapsed time in minutes and seconds

### React Concepts Used
- useState
- useEffect
- Custom Hooks
- Conditional Rendering
- Event Handling
- Props
- Lifting State Up
- Interval Cleanup

### Technologies
- React Native
- Expo
- TypeScript
